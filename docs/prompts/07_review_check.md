# 07 — レビュー・品質チェック

> **前提**: `00_rules.md` 読み込み済み、テーマが一通り完成していること
> **成果物**: 品質基準をクリアした出荷可能なテーマ

---

## このプロンプトの目的

テーマ全体を多角的にレビューし、問題を修正して品質基準を満たす状態にする。

---

## AI への指示: 総合レビュー

以下の観点でテーマ全体をレビューしてください。
対象は `theme/` ディレクトリ配下のすべてのファイルです。

---

### チェック 1: theme.json バリデーション

```markdown
## 確認事項
- [ ] JSON 構文が valid（パースエラーなし）
- [ ] `$schema` が正しい URL を指している
- [ ] `version` がサポートする WordPress バージョンに適合
- [ ] `settings` と `styles` に矛盾がない（存在しないプリセットへの参照等）
- [ ] `templateParts` の定義が `parts/` のファイルと一致
- [ ] `customTemplates` の定義が `templates/` のファイルと一致
- [ ] 不要な設定が残っていない
```

---

### チェック 2: テンプレート・パーツ構文

```markdown
## 確認事項
- [ ] 全テンプレートでブロックマークアップの開始・終了タグが一致
- [ ] `<!-- wp:template-part -->` のスラッグが `parts/` のファイル名と一致
- [ ] `<!-- wp:pattern -->` のスラッグが `patterns/` の定義と一致
- [ ] セルフクロージングタグ（`/-->`）が正しく使われている
- [ ] ネストされたブロックのインデントが整っている
- [ ] 空のブロックや不要な空行がない
```

---

### チェック 3: パターン PHP

```markdown
## 確認事項
- [ ] 全パターンファイルにコメントヘッダー（Title, Slug, Categories）がある
- [ ] Slug がテーマスラッグで始まっている（`theme-slug/pattern-name`）
- [ ] 翻訳対象の文字列が `esc_html__()` / `esc_attr__()` でラップされている
- [ ] テキストドメインが統一されている
- [ ] 画像パスに `get_theme_file_uri()` を使用している
- [ ] PHP の開始タグ（`<?php`）が正しく閉じられている
- [ ] エスケープ関数が適切に使われている
```

---

### チェック 4: functions.php

```markdown
## 確認事項
- [ ] 不要な機能が含まれていない（最小限の原則）
- [ ] 関数名にテーマプレフィックスが付いている
- [ ] フック（`add_action` / `add_filter`）が適切
- [ ] `wp_enqueue_style` / `wp_enqueue_script` が正しい
- [ ] テーマサポート（`add_theme_support`）が過不足ない
- [ ] セキュリティ上の問題がない（nonce, エスケープ等）
```

---

### チェック 5: アクセシビリティ

```markdown
## 確認事項
- [ ] 見出し階層（H1 → H2 → H3）が論理的に正しい（H1 の飛ばし等なし）
- [ ] 画像ブロックに alt テキストの入力が可能（プレースホルダーで示唆）
- [ ] ナビゲーションに `aria-label` が設定されている
- [ ] リンクテキストが「こちら」等の曖昧な表現でない
- [ ] ボタンに十分なコントラスト比がある（theme.json のカラー設定）
- [ ] フォーム要素にラベルが関連付けられている
- [ ] スキップリンクが存在する（WordPress コアが提供）
```

---

### チェック 6: レスポンシブ対応

```markdown
## 確認事項
- [ ] 375px（モバイル）でレイアウト崩れがない
- [ ] 768px（タブレット）でレイアウト崩れがない
- [ ] 1440px（デスクトップ）でレイアウト崩れがない
- [ ] カラムブロックがモバイルで適切にスタックする
- [ ] テキストがビューポートからはみ出さない
- [ ] 画像が `max-width: 100%` で収まる
- [ ] ナビゲーションがモバイルメニューに切り替わる
```

---

### チェック 7: パフォーマンス

```markdown
## 確認事項
- [ ] 未使用の CSS / JS がない
- [ ] 画像の遅延読み込み（loading="lazy"）が有効（WordPress コアのデフォルト）
- [ ] Google Fonts の読み込みが最適化されている（必要なウェイトのみ）
- [ ] `functions.php` で不要なスクリプトを読み込んでいない
- [ ] `theme.json` で不要な機能を無効化している（カスタムカラーピッカー等）
```

---

### チェック 8: WordPress Theme Check 基準

```markdown
## 確認事項
- [ ] `style.css` に必須ヘッダーがすべて含まれている
- [ ] `index.html`（または `index.php`）が存在する
- [ ] テーマスクリーンショット（`screenshot.png`）がある
  - 推奨サイズ: 1200×900px
- [ ] ライセンス表記がある（GPL-2.0-or-later 推奨）
- [ ] `readme.txt` がある（任意だが推奨）
- [ ] `theme.json` が WordPress のスキーマに準拠
```

## 自動チェックスクリプト

> 以下の検証を行うシェルスクリプトを `scripts/validate-theme.sh` として生成してください。
>
> 1. `theme.json` の JSON 構文チェック（`jq` を使用）
> 2. テンプレート内のブロックタグ開閉の一致チェック
> 3. Hex カラーコード・px 直値の残存チェック（`06` のスクリプトと統合）
> 4. パターンファイルのコメントヘッダー存在チェック
> 5. `style.css` の必須ヘッダーチェック
> 6. `screenshot.png` の存在チェック

---

## テーマのパッケージング

すべてのチェックがクリアしたら:

```bash
cd repo
zip -r theme-name.zip theme/ \
  -x "*.DS_Store" \
  -x "*__MACOSX*" \
  -x "*.git*" \
  -x "*node_modules*"
```

> このコマンドを `scripts/package-theme.sh` としてスクリプト化してください。
